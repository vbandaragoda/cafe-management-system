## Notes on evidence quality

- Every "Evidence" cell above names a real file that exists in the
  repository (`backend/`, `web/`, `mobile/`) as of this documentation pass,
  or a specific section of another doc in this `docs/` tree — not a
  generic claim.
- Rows 3 and 14 reference entities/endpoints (`Category`, `Product`,
  `CafeTable`, `Payment`, `/admin/reports/*`) that were implemented against
  this matrix's authoritative spec. The `MenuItem`/`MenuCategory` → `Product`/
  `Category` rename (and the `entity/`→`model/`, `repository/`→`repo/`
  package restructuring) has since been completed in the backend —
  `grep`-verified with zero remaining references to the old names outside
  of intentional "renamed from X" comments — so the naming in this matrix
  now matches the actual repository state, not just a target.
- Row 9 (multi-table calculation) is the assignment's most specific
  technical requirement and is backed by four independent pieces of
  evidence rather than one, per the authoritative spec.
